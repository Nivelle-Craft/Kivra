# Kivra

Kivra is a modular, all-in-one server mod for Minecraft.

## v0.1 — Permissions

The first milestone focuses on the permissions foundation:

- Users and groups
- Permission nodes
- Group inheritance
- Prefixes and weights
- Persistent JSON storage
- `/kivra` administration commands
- API foundation for future Kivra modules

## Planned modules

- Permissions
- Economy
- Essentials (homes, TPA, spawn, warps)
- Claims
- Shops
- Kits
- Moderation
- Chat
- Player data

## Target

- Minecraft 1.20.1
- Forge 47.4.10
- Java 17

> Kivra is under active development.
